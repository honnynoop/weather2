⚙️ 배치 처리 상세 흐름
Spring Batch 2개 Job의 내부 단계별 처리 과정. POST /api/batch/run/{jobName} 또는 BatchScheduler로 실행됩니다.
📈 weatherAnalysisJob POST /api/batch/run/weather-analysis
▶
JobLauncher.run(weatherAnalysisJob, params)
BatchController에서 수동 트리거. runAt + triggeredBy 파라미터로 매 실행 고유 JobInstance 생성.
params: runAt=2024-11-20T10:30:00, triggeredBy=manual-api
📖
Reader: JdbcCursorItemReader
weather.weather_data와 raw.orders를 JOIN하여 오늘 날짜 데이터를 스트리밍으로 읽습니다.
SELECT w.*, o.* FROM weather_data w JOIN orders o WHERE DATE(w.collected_at) = CURRENT_DATE
⚡
Processor: ItemProcessor<WeatherSalesRow, WeatherSalesRow>
WeatherSalesRow 데이터 유효성 검증 및 로깅. null이면 skip, 정상이면 그대로 통과.
WeatherSalesRow { city, temperature, salesAmount, orderCount, ... }
💾
Writer: JdbcBatchItemWriter chunk=10
analytics.weather_sales_corr에 UPSERT. 10건씩 트랜잭션 묶음으로 처리하여 안정성 확보.
INSERT INTO analytics.weather_sales_corr (...) ON CONFLICT DO UPDATE
✅
JobExecutionListener → COMPLETED
배치 완료. ReportService·RecommendationService에서 분석 결과 사용 가능.
status: COMPLETED | startTime | endTime
🧠 embeddingIndexJob POST /api/batch/run/embedding-index
▶
JobLauncher.run(embeddingIndexJob, params)
Tasklet 기반 단일 Step Job. weather-analysis 배치 완료 후 실행해야 최신 데이터 포함.
Job 구조: JobBuilder → Tasklet Step (단순 처리)
📖
WeatherDataRepository.findAll() — 미처리 데이터 조회
analytics.embedding_log와 LEFT JOIN하여 아직 임베딩되지 않은 WeatherData만 선별.
SELECT * FROM weather_data w WHERE NOT EXISTS (SELECT 1 FROM embedding_log el WHERE el.source_id = w.id)
🔤
toText() — 텍스트 변환
WeatherData 엔티티를 자연어 텍스트로 변환. 도시·날씨·매출 정보를 문장화.
"서울 날씨 맑음, 기온 22.5°C, 습도 55%, 당일 매출 3,200,000원, 우산 판매 증가..."
🧠
nomic-embed-text (Ollama) — 768차원 벡터 생성
텍스트를 768차원 dense vector로 변환. cosine similarity 기반 검색을 위한 임베딩.
Document { content, metadata: {city, source_id(String), date} } → float[768]
💾
VectorStore.add(documents) → vector_store 테이블
pgvector hnsw 인덱스에 벡터 저장. embedding_log에 처리 기록하여 중복 방지.
vector_store: id, content, metadata(json), embedding(vector(768))
✅
임베딩 완료 → RAG 채팅 서비스 활성화
vector_store에 인덱스 생성 완료. ChatService의 QuestionAnswerAdvisor가 유사도 검색 사용 가능.
topK=5, similarityThreshold=0.5, filterExpression(city) 지원
