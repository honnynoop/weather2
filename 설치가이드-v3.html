왜 LocalExecutor?

Redis + Celery Worker를 없애 RAM ~1.5GB 절약.
DAG 수백 개 이하의 환경에서 충분하며
나중에 EXECUTOR=CeleryExecutor 한 줄로 확장 가능.

dbt 통합 방식

dbt가 Airflow 이미지에 사전 설치됨 (Dockerfile.airflow).
런타임 pip install 없이 즉시 실행.
DAG에서 BashOperator → dbt 명령어 호출.

포트 할당 (충돌 없음 확인)

모든 호스트 포트는 고유합니다
서비스호스트 포트컨테이너 포트URL계정
PostgreSQL 5432 5432 localhost:5432 admin / Admin1234!
Airflow 8080 8080 localhost:8080 admin / admin
Superset 8088 8088 localhost:8088 admin / admin
Adminer 8889 8080 (컨테이너 내부) localhost:8889 서버: postgres
💡
Adminer와 Airflow 포트 관계

Adminer 컨테이너 내부는 8080을 씁니다. Airflow도 내부 8080. 하지만 Docker 컨테이너는 네트워크 네임스페이스가 완전히 격리되어 서로 보이지 않습니다. 호스트에서 Adminer는 8889, Airflow는 8080이므로 충돌이 없습니다.

Superset 데이터 연결 & 대시보드

🔌 PostgreSQL 데이터 소스 연결

  1. localhost:8088 접속 → admin / admin
  2. 상단 메뉴 Settings → Database Connections → + Database
  3. 드롭다운에서 PostgreSQL 선택
  4. 연결 문자열 입력:
    postgresql://admin:Admin1234!@postgres:5432/warehouse
  5. Test Connection → "Connection looks good!" 확인
  6. Connect 버튼으로 저장

📈 월별 매출 차트 생성

  1. 메뉴 Charts → + Chart
  2. Dataset: marts.monthly_sales
  3. 차트 유형: Line Chart
  4. X축: year_month / Metrics: SUM(total_revenue)
  5. Run Query → 결과 확인 → Save
  6. Dashboards → + Dashboard → 차트 추가

트러블슈팅

클릭해서 해결 방법 보기
❌ setup.bat 실행 시 한글 깨짐 / 명령어 인식 안 됨 ▼
✅ 해결: setup.bat 대신 setup.ps1을 직접 실행
PowerShell
powershell -ExecutionPolicy Bypass -File ".\scripts\setup.ps1"
❌ Airflow UI가 8080에서 안 열림 ▼
✅ airflow-init 완료 전에 webserver가 시작된 경우 airflow-init이 완전히 종료(exited 0)된 후 webserver가 시작됩니다. 1~2분 대기 후:
PowerShell
docker compose logs airflow-init            # "초기화 완료" 확인
docker compose logs --tail=30 airflow-webserver
docker compose restart airflow-webserver    # 그래도 안되면
❌ Adminer 포트 8889 접속 불가 ▼
✅ 컨테이너 실행 상태 확인 + 방화벽 체크
PowerShell
docker compose ps adminer               # State: Up 확인
docker compose logs adminer             # 오류 메시지 확인
# 포트 8889가 방화벽에 막혀있으면:
netsh advfirewall firewall add rule name="Adminer" protocol=TCP dir=in localport=8889 action=allow
❌ Superset "Database connection failed" ▼
✅ 컨테이너 내부 호스트명 사용 필수 Superset에서 PostgreSQL 연결 시 localhost가 아닌 컨테이너 서비스명 postgres를 써야 합니다.

올바른 연결 문자열: postgresql://admin:Admin1234!@postgres:5432/warehouse
❌ dbt run 실패 — "relation does not exist" ▼
✅ staging → marts 순서로 실행 marts 모델은 staging 뷰를 참조합니다. 반드시 staging 먼저:
PowerShell
docker compose exec airflow-scheduler bash -c "cd /opt/airflow/dbt && dbt run --select staging --profiles-dir /opt/airflow/dbt"
docker compose exec airflow-scheduler bash -c "cd /opt/airflow/dbt && dbt run --select marts --profiles-dir /opt/airflow/dbt"
❌ WSL2 메모리 부족 (OOM, 컨테이너 자꾸 죽음) ▼
✅ .wslconfig 파일로 WSL2 메모리 상한 설정 %UserProfile%\.wslconfig 파일 생성/수정:
.wslconfig
[wsl2]
memory=8GB
processors=4
swap=4GB
저장 후 wsl --shutdown → Docker Desktop 재시작
❌ docker compose build 실패 (pip 타임아웃) ▼
✅ 네트워크 타임아웃 — 재시도 또는 Docker 재시작
PowerShell
# Docker 캐시 없이 재빌드
docker compose build --no-cache
# 또는 Docker Desktop 재시작 후 재시도
docker system prune -f  # 불필요한 캐시 정리
