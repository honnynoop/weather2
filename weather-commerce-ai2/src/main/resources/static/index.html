Mock 날씨 데이터를 생성하고 조회합니다.

📦 히스토리 시딩

POST /api/mock/seed

과거 N일치 날씨 데이터를 6시간 간격으로 일괄 생성합니다.
생성 수 = 일수 × 4시간대 × 4도시

선택: 7일 → 예상 112건

⚡ 즉시 생성

POST /api/mock/generate

현재 시각 기준 4개 도시 날씨를 즉시 1건씩 생성합니다.

💡
히스토리가 충분하지 않을 때 현재 날씨만 빠르게 생성합니다. AI 품질 향상을 위해 시딩을 권장합니다.

📡 도시별 최신 날씨
