메서드

@PostMapping HTTP POST 요청 처리 (생성). 메서드

의존성 주입 (DI) 어노테이션

공통 5개
어노테이션 설명 적용 위치 사용 예
@Autowired 타입 기반 자동 주입. 생성자 주입 권장 (순환 의존성 방지). 단일 생성자 시 생략 가능. 필드 생성자 메서드
// 생성자 주입 (권장) @Service public class OrderService { private final OrderRepo orderRepo; private final PaymentService payService; @Autowired // 단일 생성자면 생략 가능 public OrderService(OrderRepo r, PaymentService p) { this.orderRepo = r; this.payService = p; } }
@Qualifier 같은 타입의 Bean이 여러 개일 때 이름으로 구분하여 주입. 파라미터 필드
@Autowired @Qualifier("mainDataSource") private DataSource dataSource;
@Value application.properties 값 또는 SpEL 표현식을 필드/파라미터에 주입. 필드 파라미터
@Value("${jwt.secret}") private String jwtSecret; @Value("${server.port:8080}") // 기본값 설정 private int port;
@Primary 같은 타입의 Bean이 여러 개일 때 기본 Bean으로 지정. 클래스
@Primary @Bean public DataSource primaryDataSource() { return new HikariDataSource(config); }
@Lazy Bean을 처음 사용 시점에 초기화(지연 로딩). 기동 시간 단축. 클래스
@Lazy @Service public class HeavyService { public HeavyService() { // 처음 사용 시에만 실행됨 } }

Data JPA / ORM 어노테이션

Data JPA 5개
어노테이션 설명 적용 위치 사용 예
@Entity JPA가 관리하는 영속성 엔티티 클래스임을 선언. DB 테이블에 매핑. 클래스
@Entity @Table(name = "users") public class User { @Id @GeneratedValue(strategy = GenerationType.IDENTITY) private Long id; @Column(nullable = false, length = 50) private String username; }
@Id
@GeneratedValue		 기본키 지정 및 자동 생성 전략 설정 (IDENTITY, SEQUENCE, AUTO). 필드
@Id @GeneratedValue(strategy = GenerationType.SEQUENCE, generator = "user_seq") @SequenceGenerator(name = "user_seq", allocationSize = 50) private Long id;
@OneToMany
@ManyToOne
@ManyToMany		 엔티티 간 연관관계 매핑. FetchType, cascade, orphanRemoval 설정. 필드
@OneToMany(mappedBy = "user", cascade = CascadeType.ALL, fetch = FetchType.LAZY) private List<Order> orders = new ArrayList<>();
@Query Repository 메서드에 JPQL 또는 Native SQL 직접 작성. 메서드
@Query("SELECT u FROM User u WHERE u.email = :email AND u.active = true") Optional<User> findActiveByEmail( @Param("email") String email);
@Modifying @Query와 함께 사용. UPDATE/DELETE 쿼리를 Repository에서 직접 실행. 메서드
@Modifying @Transactional @Query("UPDATE User u SET u.active = false WHERE u.id = :id") int deactivateUser(@Param("id") Long id);

AOP 어노테이션

공통 5개

@Aspect @Component public class LoggingAspect { @Around("execution(* com.example.service.*.*(..))") public Object logExecution(ProceedingJoinPoint pjp) throws Throwable { long start = System.currentTimeMillis(); Object result = pjp.proceed(); log.info("실행시간: {}ms", System.currentTimeMillis() - start); return result; } }

@AfterReturning( pointcut = "execution(* *.save(..))", returning = "result") public void afterSave(Object result) { log.info("저장 완료: {}", result); }
@Around 메서드 실행 전후를 완전히 제어. 실행 여부·반환값 변경 가능. 메서드
@Around("@annotation(Cacheable)") public Object cacheAround(ProceedingJoinPoint pjp) throws Throwable { String key = generateKey(pjp); if (cache.has(key)) return cache.get(key); Object val = pjp.proceed(); cache.put(key, val); return val; }
@Pointcut Pointcut 표현식을 재사용 가능한 메서드로 정의. 메서드
@Pointcut("execution(* com.example.service..*(..))") public void serviceLayer() {} @Before("serviceLayer()") public void logBefore(JoinPoint jp) { ... }
