STAGINGstg_customerssource('raw','customers')staging VIEWdays_since_signup, is_capital_region
STAGINGstg_productssource('raw','products')staging VIEWmargin_rate, price_tier

MARTSdim_customersstg_customers, stg_ordersmarts TABLErfm_r/f/m, customer_grade, lifetime_value
MARTSfct_ordersstg_orders, dim_customers, stg_productsmarts TABLErevenue_amount, gross_profit

실습 06 — DAG 파일 코드 설명
배포한 2개 DAG 파일의 내용과 동작 방식

DAG 1: dag_dbt_data_stack.py — 매일 자동 실행

▶ 02:00
→
dbt_debug
→
dbt_run_staging
→
dbt_run_marts
→
dbt_test
→
pipeline_done
pythondags/dag_dbt_data_stack.py (핵심 부분)
DBT_DIR = "/opt/dbt"   # 실제 확인된 경로

with DAG(
    dag_id            = "dbt_data_stack_daily",
    schedule_interval = "0 2 * * *",   # 매일 02:00
    start_date        = datetime(2024, 1, 1),
    catchup           = False,
) as dag:

    t_debug   = BashOperator(task_id="dbt_debug",
                  bash_command=f"cd {DBT_DIR} && dbt debug")
    t_staging = BashOperator(task_id="dbt_run_staging",
                  bash_command=f"cd {DBT_DIR} && dbt run --select staging")
    t_marts   = BashOperator(task_id="dbt_run_marts",
                  bash_command=f"cd {DBT_DIR} && dbt run --select marts")
    t_test    = BashOperator(task_id="dbt_test",
                  bash_command=f"cd {DBT_DIR} && dbt test")
    t_done    = BashOperator(task_id="pipeline_done",
                  bash_command='echo "파이프라인 완료: $(date)"')

    t_debug >> t_staging >> t_marts >> t_test >> t_done

DAG 2: dag_dbt_selective_run.py — 수동 트리거 전용

pythondags/dag_dbt_selective_run.py (핵심 부분)
with DAG(
    dag_id            = "dbt_selective_run",
    schedule_interval = None,   # 수동 트리거만
    params            = {"select": "marts", "exclude": ""},
) as dag:
    # Trigger DAG w/ config → select 파라미터로 모델 지정
    t_run  = BashOperator(task_id="dbt_run_selected", ...)
    t_test = BashOperator(task_id="dbt_test_selected", ...)
    t_run >> t_test
💡
사용법: Airflow UI에서 dbt_selective_run → Trigger DAG w/ config → {"select":"dim_customers"} 입력 → Trigger. 특정 모델만 재실행할 때 유용합니다.

marts.monthly_sales → Mixed Chart (Bar + Line)
Superset 경로Charts → + CHART → monthly_sales → Mixed Chart 선택
SQLSQL Lab에서 먼저 검증
SELECT
    year_month,
    SUM(total_revenue)                   AS total_revenue,
    SUM(order_count)                      AS order_count,
    ROUND(AVG(gross_margin_rate), 1)     AS avg_margin_pct,
    ROUND(AVG(avg_order_revenue), 0)    AS avg_order_value,
    AVG(mom_growth_rate)                  AS mom_growth_rate
FROM marts.monthly_sales
GROUP BY year_month
ORDER BY year_month;

실습 10 — 차트② 카테고리별 매출 구성비
marts.fct_orders → Pie Chart
SQL
SELECT
    category,
    SUM(revenue_amount)                              AS total_revenue,
    SUM(gross_profit)                                 AS total_profit,
    ROUND(SUM(gross_profit)::numeric
          / NULLIF(SUM(revenue_amount),0) * 100, 1) AS margin_pct,
    ROUND(SUM(revenue_amount) * 100.0
          / SUM(SUM(revenue_amount)) OVER (), 1)     AS share_pct
FROM marts.fct_orders
WHERE is_revenue = true
GROUP BY category
ORDER BY total_revenue DESC;

SELECT
    channel,
    SUM(total_spend)           AS total_spend,
    SUM(attributed_revenue)    AS total_revenue,
    ROUND(AVG(roas), 2)        AS avg_roas,
    ROUND(AVG(cac), 0)         AS avg_cac,
    ROUND(AVG(avg_ctr), 4)    AS avg_ctr,

실습 12 — 차트④ 고객 RFM 등급 분포
marts.dim_customers → Pie + Table Chart
SQL
SELECT
    customer_grade,
    COUNT(*)                         AS cnt,
    ROUND(AVG(lifetime_value), 0)    AS avg_ltv,
    ROUND(AVG(total_orders), 1)      AS avg_orders,
    ROUND(AVG(rfm_total), 1)         AS avg_rfm,
    ROUND(AVG(days_since_last_order),0) AS avg_recency
FROM marts.dim_customers
GROUP BY customer_grade
ORDER BY avg_ltv DESC;
