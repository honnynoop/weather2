🟢 Vue 3 개요

Vue 3는 2020년 출시된 프론트엔드 프레임워크로, Composition API와 성능 개선, TypeScript 지원 강화가 핵심입니다.

📐 MVVM 패턴 (Model-View-ViewModel)

Vue는 MVVM 패턴을 기반으로 동작합니다. ViewModel이 Model과 View 사이를 양방향 데이터 바인딩으로 연결합니다.

🌳 Virtual DOM + Reactivity System

Vue는 실제 DOM 조작 비용을 최소화하기 위해 메모리의 가상 트리(VNode)를 이용합니다. 데이터 변경 시 새로운 VNode를 만들어 이전 것과 Diff하여 변경된 부분만 실제 DOM에 반영합니다.

key 속성의 중요성: v-for에서 :key를 지정하면 Diff 알고리즘이 노드를 정확히 추적할 수 있어 불필요한 DOM 재생성을 방지합니다. key는 고유한 ID를 사용하세요.

📝 Template 디렉티브

Vue 템플릿은 HTML 기반 선언적 문법을 사용합니다. 디렉티브(directive)는 v- 접두사를 가집니다.

v-bind · v-model · v-on

<template> <!-- v-bind: 속성 바인딩 (약어: :) --> <img :src="imageUrl" :alt="imageAlt" /> <button :class="{ active: isActive, 'btn-lg': isLarge }" :style="{ color: textColor, fontSize: size + 'px' }">클릭</button> <!-- v-model: 양방향 바인딩 --> <input v-model="username" placeholder="이름 입력" /> <textarea v-model.trim="message" /> <!-- .trim 수식어 --> <input v-model.number="age" type="number" /> <!-- .number 수식어 --> <input v-model.lazy="email" /> <!-- .lazy: change 이벤트에만 동기화 --> <!-- v-on: 이벤트 바인딩 (약어: @) --> <button @click="handleClick">클릭</button> <button @click.prevent="submit">제출</button> <!-- .prevent: preventDefault --> <button @click.stop="close">닫기</button> <!-- .stop: stopPropagation --> <button @click.once="init">초기화</button> <!-- .once: 한 번만 실행 --> <input @keyup.enter="search" /> <!-- 키보드 수식어 --> </template>

v-if · v-show · v-for

<template> <!-- v-if: 조건부 렌더링 (DOM에서 제거/추가) --> <div v-if="role === 'admin'">관리자 메뉴</div> <div v-else-if="role === 'user'">일반 메뉴</div> <div v-else>게스트 메뉴</div> <!-- v-show: CSS display 토글 (DOM은 유지) --> <div v-show="isVisible">자주 토글되는 요소</div> <!-- v-for: 반복 렌더링 --> <ul> <li v-for="(item, index) in items" :key="item.id"> {{ index + 1 }}. {{ item.name }} </li> </ul> <!-- 객체 반복 --> <div v-for="(value, key) in userObj" :key="key"> {{ key }}: {{ value }} </div> <!-- template v-for: 래퍼 없이 여러 노드 반복 --> <template v-for="item in list" :key="item.id"> <dt>{{ item.term }}</dt> <dd>{{ item.desc }}</dd> </template> </template>

🔧 Composition API

Composition API는 Vue 3의 핵심 기능으로, 관련 로직을 함수 단위로 묶어 재사용성을 높입니다. <script setup>을 사용하면 간결하게 작성할 수 있습니다.

ref · reactive 상세

import { ref, reactive, toRefs, isRef } from 'vue' // ── ref: 원시값 포장 (Proxy가 아닌 RefImpl 객체) ── const count = ref(0) // count.value = 0 const name = ref('홍길동') // name.value = '홍길동' const list = ref([]) // list.value = [] count.value++ // JS에서는 .value 필수 // template 안에서는 자동 언래핑: {{ count }} (value 불필요) // ── reactive: 객체 반응형 (ES6 Proxy 래핑) ── const state = reactive({ user: { name: '이순신', age: 25 }, loading: false, items: [] }) state.user.name = '김유신' // 중첩 객체도 반응형 state.items.push({ id: 1 }) // 배열 메서드도 감지 // ── toRefs: reactive 구조분해 시 반응형 유지 ── const { user, loading } = toRefs(state) // user.value.name, loading.value 로 접근 // ── ref vs reactive 선택 가이드 ── // 원시값 단일 상태 → ref // 관련 상태를 묶어서 관리 → reactive // form 데이터 → reactive가 편리

computed

import { ref, computed } from 'vue' const firstName = ref('길동') const lastName = ref('홍') const items = ref([1, 2, 3, 4, 5]) // ── 읽기 전용 computed ── const fullName = computed(() => `${lastName.value}${firstName.value}`) // fullName.value → '홍길동' (의존성 캐싱: 의존 값 변경 시에만 재계산) const evenItems = computed(() => items.value.filter(n => n % 2 === 0)) // ── 읽기/쓰기 computed ── const fullNameRW = computed({ get: () => `${lastName.value}${firstName.value}`, set: (val) => { lastName.value = val.slice(0, 1) firstName.value = val.slice(1) } }) fullNameRW.value = '김유신' // set 호출됨

watch · watchEffect

import { ref, reactive, watch, watchEffect } from 'vue' const count = ref(0) const user = reactive({ name: '', age: 0 }) // ── watch: 명시적 소스, lazy (처음엔 실행 안 함) ── watch(count, (newVal, oldVal) => { console.log(`${oldVal} → ${newVal}`) }) // 여러 소스 동시 감시 watch([count, () => user.name], ([newCount, newName]) => { console.log(newCount, newName) }) // deep 감시 (중첩 객체 변경 감지) watch(user, (newUser) => { console.log(newUser) }, { deep: true }) // immediate: 처음부터 실행 watch(count, fetchData, { immediate: true }) // ── watchEffect: 자동 의존성 추적, 즉시 실행 ── watchEffect(() => { // 내부에서 접근한 반응형 값이 자동으로 의존성 등록 console.log(`count: ${count.value}, name: ${user.name}`) }) // 감시 중단 const stop = watchEffect(() => { /* ... */ }) stop() // 명시적 중단

🔄 컴포넌트 라이프사이클

Vue 3 컴포넌트는 생성부터 파괴까지 정해진 단계를 거칩니다. 각 단계에서 훅을 호출해 특정 작업을 수행할 수 있습니다.

🧩 컴포넌트 — Props · Emits · Slots

// ── Child.vue ── const props = defineProps({ title: { type: String, required: true }, count: { type: Number, default: 0 }, items: { type: Array, default: () => [] }, callback: { type: Function } }) const emit = defineEmits(['update:modelValue', 'submit', 'close']) // v-model 커스텀 구현 const props2 = defineProps(['modelValue']) const emit2 = defineEmits(['update:modelValue']) const value = computed({ get: () => props2.modelValue, set: (v) => emit2('update:modelValue', v) }) // ── Slot 사용 (Parent에서) ── // <Card> // <template #header>제목</template> // 본문 콘텐츠 // <template #footer="{ total }">{{ total }}개</template> // </Card> // ── defineExpose: 외부에서 접근 허용 ── defineExpose({ focus, reset })

provide · inject

// 조상 컴포넌트 (깊이 무관하게 하위에 주입) import { provide, ref } from 'vue' const theme = ref('dark') provide('theme', theme) // 반응형 그대로 전달 provide('setTheme', (t) => { theme.value = t }) // 자손 컴포넌트 (몇 단계 아래든 사용 가능) import { inject } from 'vue' const theme = inject('theme') // Ref<string> const setTheme = inject('setTheme') const config = inject('config', { default: {} }) // 기본값 설정

🍍 Pinia — 상태 관리

Pinia는 Vue 3 공식 상태 관리 라이브러리입니다. Composition API 기반으로 작성되어 TypeScript 지원과 DevTools 연동이 뛰어납니다.

// ── stores/user.js ── import { defineStore } from 'pinia' import { ref, computed } from 'vue' import { api } from '@/api' export const useUserStore = defineStore('user', () => { // State const currentUser = ref(null) const isLoading = ref(false) const users = ref([]) // Getters const isLoggedIn = computed(() => !!currentUser.value) const userCount = computed(() => users.value.length) // Actions async function login(email, password) { isLoading.value = true try { const { data } = await api.post('/auth/login', { email, password }) currentUser.value = data.user localStorage.setItem('token', data.token) } finally { isLoading.value = false } } async function fetchUsers() { const { data } = await api.get('/users') users.value = data } function logout() { currentUser.value = null; localStorage.removeItem('token') } return { currentUser, isLoading, users, isLoggedIn, userCount, login, fetchUsers, logout } }) // ── 컴포넌트에서 사용 ── const store = useUserStore() const { isLoggedIn, currentUser } = storeToRefs(store) // 반응형 유지 분해 await store.login(email, password) store.logout()

🗺 Vue Router 4

Vue Router는 SPA의 URL 라우팅을 관리합니다. createRouter로 라우터를 생성하고 RouterView에서 매칭된 컴포넌트를 렌더링합니다.

// ── router/index.js ── import { createRouter, createWebHistory } from 'vue-router' import { useUserStore } from '@/stores/user' const router = createRouter({ history: createWebHistory(), // HTML5 History API routes: [ { path: '/', component: () => import('@/views/HomeView.vue') }, { path: '/user/:id', component: () => import('@/views/UserView.vue'), meta: { requiresAuth: true } }, { path: '/admin', component: () => import('@/views/AdminView.vue'), children: [ // 중첩 라우트 { path: 'users', component: AdminUsers }, { path: 'settings', component: AdminSettings } ]}, { path: '/:pathMatch(.*)*', component: NotFound } // 404 ] }) // 전역 네비게이션 가드 (인증 체크) router.beforeEach((to) => { const store = useUserStore() if (to.meta.requiresAuth && !store.isLoggedIn) { return { path: '/login', query: { redirect: to.fullPath } } } }) // ── 컴포넌트에서 사용 ── import { useRouter, useRoute } from 'vue-router' const router = useRouter() const route = useRoute() // 파라미터/쿼리 접근 const userId = route.params.id // /user/42 → '42' const page = route.query.page // ?page=2 → '2' // 프로그래밍 방식 이동 router.push('/home') router.push({ name: 'user', params: { id: 42 } }) router.replace('/login') // history에 남기지 않음 router.go(-1) // 브라우저 뒤로

🌐 Axios — HTTP 통신

Axios는 Promise 기반 HTTP 클라이언트입니다. 인터셉터로 토큰 주입, 에러 처리를 전역으로 관리할 수 있습니다.

// ── api/index.js ── Axios 인스턴스 설정 import axios from 'axios' import router from '@/router' const api = axios.create({ baseURL: 'https://api.example.com/v1', timeout: 10000, headers: { 'Content-Type': 'application/json' } }) // Request Interceptor: 모든 요청에 토큰 자동 추가 api.interceptors.request.use( (config) => { const token = localStorage.getItem('token') if (token) config.headers.Authorization = `Bearer ${token}` return config }, (error) => Promise.reject(error) ) // Response Interceptor: 공통 에러 처리 api.interceptors.response.use( (response) => response, async (error) => { if (error.response?.status === 401) { await refreshToken() // 토큰 갱신 시도 return api.request(error.config) // 원래 요청 재시도 } if (error.response?.status === 403) router.push('/forbidden') return Promise.reject(error) } ) export default api // ── Pinia Action에서 사용 ── async function fetchUsers(page = 1) { isLoading.value = true try { const { data } = await api.get(`/users`, { params: { page, limit: 10 } }) users.value = data.items total.value = data.total } catch (e) { error.value = e.response?.data?.message ?? '오류 발생' } finally { isLoading.value = false } } async function createUser(payload) { const { data } = await api.post('/users', payload) users.value.push(data) return data } async function updateUser(id, payload) { const { data } = await api.put(`/users/${id}`, payload) const idx = users.value.findIndex(u => u.id === id) if (idx !== -1) users.value[idx] = data } async function deleteUser(id) { await api.delete(`/users/${id}`) users.value = users.value.filter(u => u.id !== id) }

🔁 Composables — 로직 재사용

Composable은 Composition API를 활용해 상태/로직을 캡슐화하는 함수입니다. use 접두사 관례를 따릅니다.

// composables/useFetch.js import { ref, watchEffect } from 'vue' import api from '@/api' export function useFetch(url) { const data = ref(null) const loading = ref(false) const error = ref(null) watchEffect(async () => { loading.value = true error.value = null try { const { data: res } = await api.get( toValue(url)) // ref 자동 해제 data.value = res } catch (e) { error.value = e } finally { loading.value = false } }) return { data, loading, error } }
// composables/useLocalStorage.js import { ref, watch } from 'vue' export function useLocalStorage(key, init) { const stored = localStorage.getItem(key) const value = ref(stored ? JSON.parse(stored) : init) watch(value, (v) => { localStorage.setItem(key, JSON.stringify(v)) }, { deep: true }) return value } // 사용: const theme = useLocalStorage('theme', 'light') theme.value = 'dark' // 자동 저장
Composable역할주요 라이브러리 (VueUse)
useFetchAPI 호출 + 로딩/에러 상태useFetch, useAsyncState
useLocalStoragelocalStorage 반응형 동기화useLocalStorage, useSessionStorage
useDebounce입력값 디바운스 처리useDebounceFn, useThrottleFn
useMouse마우스 좌표 추적useMouse, useMouseInElement
useMediaQuery반응형 브레이크포인트useMediaQuery, useBreakpoints
useIntersectionObserver무한 스크롤 / 지연 로딩useIntersectionObserver
Composable vs Mixin: Vue 2의 Mixin은 출처가 불명확하고 이름 충돌이 발생할 수 있었습니다. Composable은 반환값을 명시적으로 받아 사용하므로 출처가 명확하고 이름 충돌이 없으며 TypeScript와 완벽하게 호환됩니다.
